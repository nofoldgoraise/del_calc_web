# 배달계산기 웹 버전

배달 라이더를 위한 웹 기반 일당 계산기입니다.

운행시간, 휴식시간, 기름값, 식비, 매출 등을 입력하면
실제 순수익과 평균 단가, 시간당 배달 건수 등을 간단하게 계산할 수 있습니다.

## ✨ Features

- 실 운행시간 계산
- 총 지출 계산 (기름값 + 식비)
- 순수익 계산
- 평균 배달 단가 계산
- 시간당 배달 건수 계산
- 입력값 초기화 기능

---

## 🛠️ Built With

- Python
- Streamlit

---

## 🚀 Run Locally

```bash
pip install -r requirements.txt
streamlit run del_calc_streamlit.py
```

---

## 📌 Input

- 총 운행시간

- 기름값
- 식비

- 배달 건수
